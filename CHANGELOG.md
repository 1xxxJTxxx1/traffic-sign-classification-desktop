# Changelog

Все значимые изменения проекта фиксируются в этом файле.

## [1.0.0] - 2026-04-22

### Added
- Desktop-приложение на Tkinter для классификации дорожных знаков.
- Самописная CNN `TrafficSignCNN` (без готовых backbone-моделей).
- Подготовка открытого датасета GTSRB с формированием train/val/test/demo split.
- Обучение с поддержкой CUDA и автоматическим fallback на CPU.
- Ранняя остановка, сохранение лучших и последних весов.
- Умный auto-режим: проверка актуальности весов по fingerprint датасета и сигнатуре архитектуры.
- Одиночный и пакетный режимы инференса, top-3 предсказания, экспорт результатов в CSV.
- Отчёты обучения: `training_report.json`, `train_history.csv`, `confusion_matrix.png`.

### Changed
- Полностью переработана документация репозитория (`README.md`) под формат пэт-проекта.

### Notes
- Проект учебный, поэтому для промышленного использования потребуются дополнительные данные и калибровка под реальную среду.
