# Классификация дорожных знаков на изображении

Учебный desktop-проект по компьютерному зрению на Python.
Приложение распознаёт дорожный знак на фото и показывает:
- предсказанный класс;
- уверенность модели;
- top-3 наиболее вероятных класса;
- статус результата (`уверенно`, `средне`, `сомнительно`).

Проект сделан как «самописная нейронка» без готовых backbone-моделей, что удобно для защиты курсовой: вся архитектура прозрачна и объяснима.

## Что внутри
- `main.py` — единая точка входа (подготовка данных, обучение, запуск приложения).
- `src/prepare_dataset.py` — загрузка и подготовка открытого датасета GTSRB.
- `src/model.py` — самописная CNN `TrafficSignCNN`.
- `src/train.py` — обучение, валидация, тест, ранняя остановка, сохранение лучших весов.
- `src/inference.py` — инференс и top-3 предсказания.
- `src/gui.py` — отдельный интерфейс на Tkinter (одиночный режим, пакетный режим, вкладка о модели).
- `assets/reference_icons/` — эталонные иконки знаков для интерфейса.

## Почему выбрана именно такая модель
- Требование курсового проекта: самописная CNN, а не transfer learning на готовых сетях.
- Архитектура из `Conv + BN + ReLU + Pool + Dropout` хорошо работает на GTSRB и остаётся понятной для объяснения.
- Модель лёгкая и запускается как на GPU, так и на CPU.
- Баланс «качество/скорость» подходит для интерактивного desktop-приложения.

## Почему выбран датасет GTSRB
- Открытый и общепринятый датасет для распознавания дорожных знаков.
- Содержит 43 класса с реальными дорожными условиями съёмки.
- Хорошо подходит под учебную задачу классификации и честной оценки качества.

## Быстрый старт

### 1) Установка зависимостей
```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

### 2) Рекомендуемый запуск (умный auto-режим)
```powershell
python main.py
```

Логика auto-режима:
- если всё актуально, сразу запускается приложение;
- если весов нет, запускается обучение;
- если изменился датасет или архитектура, запускается переобучение.

### 3) Ручные режимы (по необходимости)
```powershell
python main.py --mode prepare   # подготовка датасета
python main.py --mode inspect   # сводка по датасету
python main.py --mode train     # обучение
python main.py --mode app       # запуск интерфейса
```

## Обучение и воспроизводимость
- Используется `CUDA`, если доступна; иначе автоматически применяется `CPU`.
- Есть ранняя остановка (`early stopping`) для снижения риска переобучения.
- Лучшие веса сохраняются в `artifacts/models/traffic_sign_cnn_best.pth`.
- Проверяется совместимость весов с текущим датасетом и архитектурой через fingerprint и signature.

## Ключевые артефакты
- `artifacts/models/traffic_sign_cnn_best.pth` — лучшие веса модели.
- `artifacts/models/traffic_sign_cnn_last.pth` — последние веса.
- `artifacts/reports/training_report.json` — итоговые метрики обучения.
- `artifacts/reports/train_history.csv` — история эпох.
- `artifacts/reports/confusion_matrix.png` — матрица ошибок.
- `data/processed/manifest.csv` — подготовленный список файлов для train/val/test/demo.
