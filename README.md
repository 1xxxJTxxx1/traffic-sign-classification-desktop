# traffic-sign-classification-desktop

Desktop-приложение на Tkinter для классификации дорожных знаков на изображениях.

## Что внутри
- Самописная CNN (без готовых backbone-моделей).
- Открытый датасет GTSRB.
- Top-3 предсказания, уверенность и статус результата.
- Пакетная обработка папки изображений и экспорт в CSV.
- Сохранение лучших весов и умный автозапуск без лишнего переобучения.

## Быстрый старт

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

0) Умный авто-запуск (рекомендуется):
```bash
python main.py
```
Логика авто-режима:
- если веса актуальны и ничего не изменилось: сразу открывается приложение;
- если весов нет: запускается обучение, затем приложение;
- если изменился датасет или архитектура модели: запускается переобучение, затем приложение.

1) Подготовка датасета (скачивается один раз):
```bash
python main.py --mode prepare
```

2) Просмотр сводки датасета:
```bash
python main.py --mode inspect
```

3) Обучение:
```bash
python main.py --mode train
```

4) Запуск интерфейса:
```bash
python main.py --mode app
```

## Структура
- `main.py` — единая точка входа.
- `src/prepare_dataset.py` — загрузка/разбиение GTSRB и формирование manifest.
- `src/model.py` — самописная CNN.
- `src/train.py` — обучение, валидация, тест и сохранение артефактов.
- `src/inference.py` — инференс и top-3.
- `src/gui.py` — Tkinter-интерфейс (3 вкладки).
